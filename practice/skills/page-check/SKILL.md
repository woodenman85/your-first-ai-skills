# Page check

Read the supplied page and the approved business facts.
Report incorrect or missing facts with the relevant text.
Check whether the hours and location are easy to find at phone width.
If you cannot view the page in a browser, state which visual checks remain.
Suggest up to three changes. Wait for a request to edit before changing files.
