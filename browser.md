# Connect a browser

- **Claude Code**. Follow Anthropic’s Chrome setup for the extension, sign-in, and connection. [Claude Code with Chrome](https://code.claude.com/docs/en/chrome)
- **Codex**. Follow OpenAI’s browser extension setup for the desktop app and select your browser from a Codex chat. [ChatGPT browser extension](https://learn.chatgpt.com/docs/chrome-extension)

To check the connection, open the public page from [the research exercise](practice/research-task.md) and ask the assistant to report its visible heading. Compare the answer with the screen. Use the browser permission settings to review or remove the site's access afterward.
