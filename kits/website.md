# Build a small website

Use `kits/website.md` in the setup prompt. Start with [Ponytail](https://github.com/DietrichGebert/ponytail) for keeping the change small and [Impeccable](https://github.com/pbakaus/impeccable) for design feedback.

- Find the project installation instructions for your assistant in each upstream README. Ask your assistant to identify the exact Ponytail skill or plugin being installed.
- For Impeccable, start with the upstream manual-copy option for the selected assistant. The README lists the Claude Code and Codex builds under `.claude/` and `.agents/`. The exercise uses the skill instructions. Review any optional hooks or live tooling separately.

## Try it

> Open practice/bakery.html and tell me what makes the page hard to use. Use Ponytail to keep the scope small and Impeccable to improve the visual hierarchy. Save the revision as practice/bakery-revised.html. Keep the bakery name, hours, and location the same.

Open both HTML files in a browser. At phone width, check that you can read the opening hours and address without zooming or scrolling sideways. Compare what changed and decide whether each change helps a visitor.
